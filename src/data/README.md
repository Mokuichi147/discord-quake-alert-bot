# 観測点の座標データ

`observation_stations.tsv` は、気象庁の「震度観測点」マップが使用する公開JSONを、quake-alert-botが都道府県名・観測点名・緯度・経度のTSVに加工したものです。

- 出典：[気象庁「震度観測点」](https://ds.data.jma.go.jp/eqev/data/intens-st/)
- 元データ：[stations.json](https://ds.data.jma.go.jp/eqev/data/intens-st/stations.json)
- 取得・利用確認日：2026-09-08（日本時間）
- 収録：4,368地点（気象庁671、地方公共団体2,896、防災科学技術研究所801）
- 現在のTSVは4,368行で、都道府県・観測点名の重複はありません（座標の完全一致もありません）。
- 入力データのSHA-256・生成日はTSV先頭に記録しています。生成日は観測点情報の更新日ではありません。
- P2P地震情報の551は、このTSVとは別の気象庁XMLコード表をもとに地点名を更新する場合があります。botは名称が一致したときだけ座標を使い、名称が更新された地点へ旧座標を推測で割り当てません。

## TSV形式

座標データは `observation_stations.tsv` に統合しています。先頭の `#` 行は出典などのコメントです。

```text
都道府県<TAB>観測点名<TAB>緯度<TAB>経度
```

実行時の照合は都道府県と観測点名の組み合わせを使います。

## 利用条件・加工内容

気象庁の[利用規約](https://www.jma.go.jp/jma/kishou/info/coment.html)は、別の権利表記がない公開情報に[公共データ利用規約 第1.0版](https://www.digital.go.jp/resources/open_data/public_data_license_v1.0)を適用しています。規約は複製・加工・公衆送信・商用利用を認め、数値データ等は著作権の保護対象外として自由に利用できるとしています。第三者が権利を持つコンテンツには別途その権利への配慮が必要です。確認した観測点ページとJSONには、この座標データについて別の利用条件を指定する表示はありませんでした。

本データは気象庁の公開JSONから取得しています。防災科学技術研究所などの別サイトから配布されるデータの利用条件を、そのまま本データへ適用するものではありません。以前のREADMEにあった「NIEDは再配布禁止なので収録できない」という一律の説明は撤回しました。

出典と加工主体をこのファイル・TSV先頭・地図添付時の通知フッターに明記しています。データの配布時にもこの説明を同梱してください。リポジトリ本体のUnlicenseによって元データの利用条件を変更するものではありません。

## 精度と照合

- 公開JSONは小数点以下2桁の座標です。地点単位にプロットできますが、緯度0.01度は約1.1kmであり、施設の厳密な位置を示す精度ではありません。
- 座標は公開JSONに含まれる現行値だけを使用します。旧座標の補完、移転履歴の推測、公開JSONにない旧観測点の追加は行いません。
- botは都道府県と観測点名を組み合わせて完全一致で照合します。都・府・県の接尾辞の違いは吸収します。
- 551の`points.isArea=true`は観測点ではなく区域名です。区域名の座標はこのTSVから引かず、都道府県代表座標へ集約します。551の`points.isArea=false`だけが観測点TSVの照合対象です。
- 未収録の観測点、震度速報・緊急地震速報の地域名は従来どおり都道府県代表座標へ集約します。このデータで地域の境界・代表点を求めることはできません。

## 更新方法

リポジトリのルートで実行します。Python 3の標準ライブラリのみを使用します。

```sh
python3 scripts/update_observation_stations.py
```

取得済みJSONから再生成する場合：

```sh
python3 scripts/update_observation_stations.py --input /path/to/stations.json
```

入力の空配列・重複・不正な座標・都道府県コードは、既存TSVを書き換える前にエラーにします。生成後は差分、件数、移転や名称変更を確認し、次の検証を行って再ビルドしてください。

```sh
python3 -B -m unittest discover -s scripts -p 'test_*.py'
cargo test --offline
cargo build --release
```

公開JSONはマップ用の静的ファイルであり、固定仕様のAPIとしての保証は確認できません。URL・形式の変更時は更新スクリプトを見直してください。bot稼働時には組み込みTSVを使うため、取得先の障害は通知処理へ影響しません。
